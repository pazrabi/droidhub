# Пошаговая настройка Android-телефона для DroidHub

Эта инструкция написана простым языком для начинающих. Следуя ей шаг за шагом, вы подготовите любой Android-телефон (включая Realme и Redmi) к удалённому управлению через DroidHub.

В результате телефон будет лежать дома на зарядке, подключенный к домашнему Wi-Fi, а вы, веб-панель или нейросеть сможете управлять им через защищённую сеть Tailscale из любой точки мира.

---

## Что понадобится перед началом

1. **Телефон на Android** (например, Realme C21Y или Redmi Note 11), подключенный к вашему домашнему Wi-Fi.
2. **Рабочий компьютер (MacBook)** с кабелем USB для подключения телефона.
3. **Зарядное устройство** (блок питания + провод), на котором телефон будет стоять постоянно.
4. **Аккаунт Tailscale** (бесплатный, зарегистрированный на [tailscale.com](https://tailscale.com)).

---

## Шаг 1. Включение «Режима разработчика»

По умолчанию настройки для разработчиков в Android скрыты, чтобы обычные пользователи случайно ничего не сломали. Их нужно включить:

### На Realme (Realme UI / чистый Android)
1. Откройте **«Настройки»** телефона.
2. Пролистайте в самый низ и выберите пункт **«О телефоне»** (или «Об устройстве»).
3. Найдите раздел **«Версия»** (или «Радиомодуль и ядро») и найдите строку **«Номер сборки»**.
4. **Быстро нажмите на «Номер сборки» 7 раз подряд.**
5. Телефон может попросить ввести пароль/пин-код разблокировки. Введите его.
6. На экране появится сообщение: *«Вы стали разработчиком!»*.
7. Где искать меню: вернитесь в **«Настройки»** → **«Система»** (или **«Дополнительные настройки»**) → **«Для разработчиков»**.

### На Redmi (MIUI / HyperOS)
1. Откройте **«Настройки»** телефона.
2. Нажмите на самый верхний пункт **«О телефоне»**.
3. Найдите строку **«Версия MIUI»** (или **«Версия OS»** в HyperOS).
4. **Быстро нажмите на неё 7 раз подряд.**
5. Появится надпись: *«Не нужно, вы уже разработчик!»*.
6. Где искать меню: вернитесь в **«Настройки»** → пролистайте вниз до **«Расширенные настройки»** → внизу выберите **«Для разработчиков»**.

---

## Шаг 2. Базовые настройки разработчика и экрана

Зайдите в меню **«Для разработчиков»** (из Шага 1) и включите три важных параметра:

1. **Отладка по USB (USB debugging)**:
   - Включите переключатель.
   - Появится окно предупреждения о безопасности. Нажмите **«ОК»** (или подождите таймер и нажмите «Принять»).

2. **Не выключать экран при зарядке (Stay awake)**:
   - Включите этот тумблер.
   - Теперь, пока телефон подключен к зарядному устройству, экран не будет гаснуть и блокироваться.

3. **Отключение блокировки экрана (критично!)**:
   - Перейдите в **«Настройки»** → **«Пароли и безопасность»** → **«Блокировка экрана»**.
   - Нажмите **«Отключить защиту»** (или выберите режим «Нет» / «Провести по экрану»).
   - **Зачем это нужно**: если телефон случайно уснёт или перезагрузится, он не должен требовать ввод графического ключа или пин-кода. Хаб сможет сразу «разбудить» устройство.

## Шаг 3. Особенности Redmi (MIUI / HyperOS) и их обход

> Если вы настраиваете **Realme** — можете сразу переходить к **Шагу 4**.  
> Если вы настраиваете **Redmi / Xiaomi / POCO** — обязательно прочитайте этот раздел.

### В чём сложность с Redmi?
В смартфонах Xiaomi встроен фирменный центр безопасности MIUI Security. Если включить только обычную «Отладку по USB», компьютер сможет делать скриншоты, но **не сможет нажимать на экран (тапать), свайпать и вводить текст** (Android выдаст ошибку прав доступа `InjectPermissionException`).

Чтобы разрешить удалённое управление, на Redmi необходимо включить специальный тумблер:
**«Отладка по USB (настройки безопасности)»** *(USB debugging (Security settings))*.

### Проблема отсутствия SIM-карты
При попытке включить этот тумблер MIUI требует:
1. Войти в Mi-аккаунт на телефоне.
2. Иметь вставленную SIM-карту с мобильным интернетом для отправки верификационного SMS.

### Как это обойти (два способа):

#### Способ 1: Временная SIM-карта (самый надёжный, занимает 5 минут)
1. Временно достаньте SIM-карту из своего основного телефона и вставьте в Redmi.
2. Войдите в свой Mi-аккаунт в **«Настройки»** → **«Mi аккаунт»** (если его нет — зарегистрируйте прямо на телефоне).
3. Зайдите в **«Для разработчиков»** и включите тумблер:
   - **«Установка через USB»** (Install via USB);
   - **«Отладка по USB (настройки безопасности)»** (USB debugging (Security settings)).
4. Телефон покажет **три предупреждения подряд с 10-секундным таймером**. Дождитесь окончания каждого таймера и нажмите *«Следующий шаг»*, а в конце — *«Принять»*.
5. **Готово!** Теперь вытащите SIM-карту и верните её в свой основной телефон.  
   Настройка сохраняется навсегда (до полного сброса телефона к заводским настройкам). Без SIM-карты всё продолжит отлично работать по Wi-Fi!

#### Способ 2: Отключение оптимизации MIUI (если SIM-карты нет под рукой)
1. В меню **«Для разработчиков»** пролистайте в самый-самый низ.
2. Найдите кнопку **«Восстановить значения по умолчанию»** и нажмите на неё быстро 4–5 раз.
3. Чуть ниже появится скрытый пункт **«Включить оптимизацию MIUI»** (Turn on MIUI optimization).
4. Выключите этот переключатель и перезагрузите телефон.
5. На многих версиях MIUI это снимает запрет на управление вводом без авторизации через SIM.

## Шаг 4. Установка Tailscale и настройка батареи

Tailscale объединяет ваши устройства (сервер, ноутбук и телефоны) в одну зашифрованную приватную сеть. Каждому телефону выдаётся постоянный IP-адрес вида `100.x.x.x`. Доступ к телефону из внешнего интернета полностью закрыт — управлять им смогут только устройства из вашей сети Tailscale.

### Установка Tailscale:
1. Установите приложение **Tailscale** из Google Play (или скачайте APK с официального сайта / GitHub).
2. Запустите приложение и нажмите **«Log in»**.
3. Войдите в **тот же самый аккаунт**, к которому подключены сервер и MacBook.
4. Нажмите переключатель **«Connect»** в верхней части экрана.
5. Android попросит разрешение на создание VPN-соединения — нажмите **«ОК»**.
6. В приложении отобразится Tailscale IP вашего телефона (например, `100.64.0.2`). **Запишите его!**

### Настройка энергосбережения (чтобы телефон не «убивал» Tailscale):
Android активно усыпляет фоновые приложения для экономии заряда. Нам нужно запретить ему трогать Tailscale:

1. **Отключение контроля батареи**:
   - Перейдите в **«Настройки»** → **«Приложения»** → **Tailscale** → **«Питание и производительность»** (или «Контроль активности»).
   - Выберите вариант **«Без ограничений»** (No restrictions).

2. **Постоянный VPN (Always-on VPN)**:
   - Перейдите в **«Настройки»** → **«Подключение и общий доступ»** (или «Сеть и интернет») → **«VPN»**.
   - Нажмите значок шестерёнки рядом с Tailscale.
   - Включите тумблер **«Постоянная VPN»** (Always-on VPN).

3. **Автозапуск (для Redmi)**:
   - В **«Настройки»** → **«Приложения»** → **«Разрешения»** → **«Автозапуск в фоновом режиме»** включите тумблер для Tailscale.

4. **Защита аккумулятора**:
   - Поскольку телефон будет постоянно стоять на зарядке, найдите в настройках батареи пункт **«Защита аккумулятора»** или **«Оптимизированная зарядка»** (ограничение уровня заряда до 80–85%) и включите её, чтобы аккумулятор не вздулся со временем.

## Шаг 5. Активация `adb tcpip 5555` с MacBook

По умолчанию из соображений безопасности Android слушает команды ADB только через физический провод. Чтобы телефон начал принимать команды по сети (через Wi-Fi и Tailscale), его нужно перевести в режим сетевой отладки. Это делается один раз через провод с компьютера.

### 1. Установка ADB на MacBook
Откройте приложение **Terminal** на Mac. Если у вас ещё не установлены инструменты Android Platform Tools, выполните команду (требуется установленный Homebrew):
```bash
brew install android-platform-tools
```

### 2. Подключение по кабелю
1. Подключите телефон к MacBook оригинальным или качественным USB-кабелем.
2. Разблокируйте экран телефона. На экране появится запрос:  
   *«Разрешить отладку по USB с этого компьютера?»*.
3. **Обязательно поставьте галочку «Всегда разрешать с этого компьютера»** и нажмите **«Разрешить»** (или «ОК»).

### 3. Проверка подключения
В терминале Mac выполните:
```bash
adb devices
```
Вы должны увидеть серийный номер вашего телефона и статус `device`:
```text
List of devices attached
988a1b414d455444    device
```
*(Если статус `unauthorized` — проверьте экран телефона и подтвердите запрос доверия)*.

### 4. Включение сетевого режима
Выполните команду:
```bash
adb tcpip 5555
```
В терминале появится ответ:
```text
restarting in TCP mode port: 5555
```
**Ура!** Теперь отсоедините провод от Mac. Подключите телефон к блоку питания и поставьте его на постоянное место рядом с Wi-Fi роутером.

## Шаг 6. Установка ADBKeyBoard для ввода кириллицы

Встроенная в Android команда `adb shell input text` умеет печатать только английские буквы, цифры и базовые символы. Кириллицу (русские буквы), эмодзи и сложные пробелы она не воспринимает — текст превращается в пустоту или ошибку.

Для решения этой проблемы мы используем виртуальную клавиатуру **ADBKeyBoard**. Она работает в фоновом режиме и принимает текст на любом языке в кодировке Base64.

### Как установить:
1. Скачайте APK-файл клавиатуры со страницы официальных релизов на GitHub:  
   👉 [github.com/senbox-org/ADBKeyBoard/releases](https://github.com/senbox-org/ADBKeyBoard/releases)  
   (вам нужен файл `ADBKeyBoard.apk`).
2. Установите её на телефон командой с Mac:
   ```bash
   adb install ADBKeyBoard.apk
   ```
   *(Если телефон уже отключен от кабеля, можно установить по сети, указав Tailscale IP: `adb -s 100.x.x.x:5555 install ADBKeyBoard.apk`).*
3. Активируйте клавиатуру в системе:
   ```bash
   adb shell ime enable com.android.adbkeyboard/.AdbIME
   adb shell ime set com.android.adbkeyboard/.AdbIME
   ```
4. Проверьте, что русский ввод работает:
   ```bash
   adb shell am broadcast -a ADB_INPUT_B64 --es msg $(echo -n "Привет от DroidHub!" | base64)
   ```
   DroidHub автоматически использует этот механизм при отправке текста на русском языке.

## Шаг 7. Проверка подключения (`adb connect`)

Теперь проверим, что телефон доступен полностью без проводов через Tailscale.

### 1. Проверка с вашего MacBook
Убедитесь, что Tailscale запущен на MacBook. В терминале выполните (замените `100.64.0.2` на Tailscale IP вашего телефона):
```bash
adb connect 100.64.0.2:5555
```
Ответ должен быть:
```text
connected to 100.64.0.2:5555
```

Проверьте отправку нажатия кнопки «Домой»:
```bash
adb -s 100.64.0.2:5555 shell input keyevent KEYCODE_HOME
```
Посмотрите на экран телефона — телефон должен выйти на главный экран!

### 2. Проверка с сервера в Амстердаме
Подключитесь к серверу по SSH:
```bash
ssh root@193.41.86.92
```

Подключитесь к телефону:
```bash
adb connect 100.64.0.2:5555
adb devices
```
В списке `adb devices` телефон должен отображаться как:
```text
100.64.0.2:5555    device
```

Теперь добавьте этот телефон в конфигурационный файл хаба `/opt/droidhub/config/devices.yaml`:
```yaml
devices:
  - id: redmi
    name: Redmi Note 11
    host: 100.64.0.2
    port: 5555
```

## Важная памятка: что делать, если телефон перезагрузился

По правилам безопасности Android после полной перезагрузки телефона сетевой порт 5555 **автоматически закрывается**. Телефон снова начинает ждать подключения по кабелю.

Если телефон перезагрузился (например, отключили электричество или сели батарейки):
1. Подключите телефон USB-кабелем к MacBook.
2. В терминале Mac выполните одну команду:
   ```bash
   adb tcpip 5555
   ```
3. Отключите провод и верните телефон на постоянную зарядку.  
   Хаб на сервере автоматически восстановит связь в течение 30 секунд.
