# Подключение нового телефона к хабу

Проверено на Honor 7A (DUA-L22, Android 8.1), Huawei P30 lite (Android 10), Redmi 9T (MIUI 12/14) и Realme C21Y. Root не нужен.

## Что нужно
- Mac с USB-кабелем (кабель для передачи данных, не только зарядка)
- platform-tools (adb): https://developer.android.com/tools/releases/platform-tools
- на телефоне Tailscale, вход в сеть владельца хаба

## Шаг 1. Режим разработчика
Настройки → О телефоне → 7 раз нажать «Номер сборки».
Настройки → Для разработчиков → включить «Отладка по USB».

## Шаг 2. Кабель и разрешение отладки
Подключить кабель. На экране телефона «Разрешить отладку по USB?» → «Разрешить» и галочка «Всегда разрешать».

```bash
adb devices   # строка со словом device
```

## Шаг 3. Wi-Fi ADB (порт 5555)
```bash
adb tcpip 5555
adb shell ip addr show | grep "100\."   # адрес Tailscale, например 100.x.x.x
```
Кабель после этого можно вытащить. Если порт при этом пропал, смотри раздел «Если порт пропадает» ниже.

## Шаг 4. Добавить в хаб
Строку вида `- {id: <id>, name: "<название>", host: 100.x.x.x, port: 5555}` дописать в `config/devices.yaml` на сервере и перезапустить хаб (около двух минут).

## При каждой перезагрузке телефона
Порт 5555 сбрасывается. Подключить кабель на 5 секунд, выполнить `adb tcpip 5555`, вытащить кабель.

## Если порт пропадает или телефон не слушается

### Huawei / Honor: порт 5555 пропадает при отключении кабеля
Включить в «Для разработчиков» пункт **«Разрешить отладку по ADB только при зарядке»** (в оригинале «Allow ADB debugging in charge only mode», перевод у Huawei кривой). После этого порт переживает отключение кабеля. Root для этого не нужен. Ошибочно считали, что без root не обойтись.

### Xiaomi / Redmi: телефон не просыпается и не принимает нажатия
Включить отдельный переключатель **«Отладка по USB (Настройки безопасности)»** в «Для разработчиков» (нужны вход в Mi-аккаунт и SIM или мобильный интернет). Пока он выключен, MIUI молча игнорирует нажатия и клавиши, в том числе `KEYCODE_WAKEUP`. Признак: `getprop persist.security.adbinput` пустой, а должно быть `1`. Root не нужен (у Redmi Note 11 root нет, проверено).

### Окно «хранилище учётных данных, задайте PIN»
Его открывает Chrome, когда сайт просит клиентский сертификат (`com.android.keychain` → `CredentialStorage`). Обойти нельзя, PIN ставить не стоит (хаб не вводит PIN). Не открывать такие сайты на этом телефоне и закрывать окно кнопкой «Назад».

### Shizuku и MacroDroid
Постоянный порт они не дают: без root `setprop persist.adb.tcp.port` и перезапуск adbd запрещены. Для задач хаба не нужны.

### Не работает ADB после обрыва
`adb disconnect <ip>:5555` и `adb connect <ip>:5555` на сервере (от пользователя `hub`).

## Tailscale и батарея
Для Tailscale отключить ограничения батареи (Huawei/Honor: «Запуск приложений» → ручное управление, все три пункта; «Игнорировать оптимизацию батареи»), закрепить в недавних.
